Habit Tracker

Description

A simple console-based habit tracker written in Python.

Features:
- Add habits from 5 built-in templates:
  - Gym
  - Watermaxxing
  - Read
  - Meditate
  - Clean Air Maxxing
- Create custom habits
- Set preferred days and times
- Log habit completions
- Track progress and streaks
- Edit and remove habits
- Save data between sessions

Requirements

- Python 3.10 or newer

How to Run

1. Extract the project files.
2. Open a terminal in the project folder.
3. Run:

python main.py

Usage

After starting the program, use the menu to:
1. View habits
2. Add a habit
3. Log completion
4. View progress
5. Remove a habit
6. Edit a habit
7. View notes
8. Exit

Files

- main.py - application entry point
- models.py - data models
- storage.py - saving and loading data
- utils.py - helper functions
- decorators.py - decorators used by the application
- exceptions.py - custom exceptions
